### 🚀 Featured project

#### [SasoFlow — AI-Powered Clinic Reception & Appointment Automation](https://github.com/ventss127/sasoflow-clinic-automation)

An **independently developed, functional prototype** that connects WhatsApp, AI, Google Calendar, and Google Sheets to support dental-clinic reception workflows.

- Handles incoming WhatsApp messages and common enquiries using AI-assisted intent recognition.
- Checks appointment availability and records bookings in Google Calendar and Google Sheets.
- Includes a custom reception dashboard for managing conversations and human handoffs.
- Pauses automated replies when a receptionist takes over, then resumes after resolution.
- Runs on a self-hosted n8n deployment on a Hetzner VPS.
